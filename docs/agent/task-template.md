# Task-card template

```text
Task ID:
Requirement IDs:
ADR IDs:
Allowed files:
Forbidden files:
Expected behavior:
Tests to add/update:
Commands to run:
Acceptance criteria:
Rollback notes:
```

## Rules

- Allowed files must be specific.
- Forbidden files must list product implementation areas when the task is infrastructure/design-only.
- Commands must be runnable locally.
- Acceptance criteria must be objective.
