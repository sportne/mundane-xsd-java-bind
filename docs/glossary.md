# Glossary

| Term | Meaning |
|---|---|
| Binding | Mapping from XML Schema components to generated Java types and codecs. |
| Codec | Generated reader/writer logic for XML serialization/deserialization. |
| Component graph | Resolved graph of schema components: elements, types, attributes, groups, and references. |
| Generated runtime path | Code executed by generated model/reader/writer/validator code. |
| IR | Intermediate representation between raw XSD parsing and Java code generation. |
| Profile | Named supported subset or compatibility contract. |
| Resolver | Component responsible for locating schema documents, includes, imports, and catalogs. |
